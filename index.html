The Problem

Finding an internship should be less confusing.

Students can struggle to find opportunities that fit their skills. InternMatch AI organizes job discovery and helps students understand how well an opportunity aligns with their profile.

⌕

Scattered Opportunities

Job listings come from different sources and can be difficult to organize in one place.

◎

Unclear Relevance

Students need a practical way to compare opportunities with their skills and preferences.

✦

Trust Signals

Heuristic signals can highlight listings that may deserve extra review before applying.

Matching Logic

How the match score is calculated.

The matching engine uses weighted rules to compare a student profile with job details. The percentages below represent the configured scoring weights.

Weighted Criteria

Each criterion contributes to the overall match score.

Skills45%
Job Role20%
Domain / Education / Interests10%
Location10%
Work Mode7.5%
Opportunity Type7.5%

Total configured weight: 100%. A match score indicates profile alignment, not a guarantee of selection.

Matching Pipeline

From external job data to personalized results.

Job Providers ↓ Fetch Job Listings ↓ Normalize Job Data ↓ Remove Duplicates ↓ Calculate Trust / Risk Signals ↓ Compare Profile with Job ↓ Calculate Match Score ↓ Rank Relevant Opportunities

AI-assisted analysis supports selected backend workflows. The core weighted matching score is rule-based, not generated entirely by AI.

System Design

How the technology stack works together.

The React frontend communicates with the Express backend through APIs. MongoDB stores application data, while external providers supply job listings.

High-Level Architecture

STUDENT │ ▼ REACT FRONTEND │ HTTP / REST API ▼ NODE.JS + EXPRESS ├── Authentication ├── Profiles ├── Jobs & Matching ├── Applications ├── Notifications └── AI Services │ ├── MongoDB Atlas ├── JSearch API ├── Adzuna API ├── Jooble API └── Mistral AI

External integrations depend on valid credentials, provider access, and service availability.

Technology Responsibilities

  • React: User interface and page navigation.
  • Node.js: JavaScript runtime for the backend.
  • Express: API routes and request handling.
  • MongoDB: Persistent storage for application data.
  • Mistral AI: Selected AI-assisted backend tasks.
  • External APIs: Fetch job listing data.
  • JWT + HTTP-only cookies: Authentication mechanism.
  • Socket.IO: Initialized for real-time communication; live notification delivery is not currently implemented.

Project Scope

What works today and what comes next.

Separating implemented functionality from future improvements makes the project easier to evaluate.

Implemented Capabilities

Core functionality included in the current project.

  • Registration and login with protected routes.
  • User profile management.
  • External job API integrations when configured.
  • Job normalization and duplicate removal.
  • Weighted profile-to-job matching.
  • Heuristic job trust and risk signals.
  • Application records with SAVED and APPLIED statuses.
  • REST-based notification data and retrieval.
  • Selected Mistral AI backend features.

Future Improvements

Possible next steps for extending the platform.

  • Company dashboard for recruiters and employers.
  • Candidate shortlisting and interview scheduling.
  • Email verification and SMTP email workflows.
  • Resume upload and automatic resume extraction.
  • Dedicated frontend experience for AI resume generation.
  • Live Socket.IO notification delivery.
  • More advanced job verification and company checks.
  • Additional testing, monitoring, and deployment hardening.

Important: SAVED and APPLIED represent in-platform application statuses. The current project does not submit applications directly to employers. Trust signals are heuristic and do not guarantee that a job is legitimate.
